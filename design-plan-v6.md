# Le Chonk Plays Civ: Design + Plan (v6 — normative, self-contained)

Challenge: Mistral Discord challenge — a harness letting `mistral-large-4` (Mistral Studio API) play Civilization VI. Judged on complexity, performance, reproducibility. Submission: video, GitHub repo with README, development story. Ends 2026-10-30 (challenge-rules compliance is verified against the official rules text in WP7 — the deadline and submission requirements are plan-internal assumptions until then). This document supersedes v1–v5 entirely; no earlier draft is normative.

## 1. Decision record

1. **Game: Civilization VI**, native Linux build (Proton does not expose the interface). Chosen for local availability + FireTuner; no claims about other Civ titles. **Pinned and recorded in the run config: game build, DLC set, difficulty, game speed, map size, barbarians setting, autosave interval (1 turn), victory types, an empty mods folder, and Steam auto-update disabled for the run window.**
2. **Interface: FireTuner.** TCP 127.0.0.1:4318; `EnableTuner 1` in `~/.local/share/aspyr-media/Sid Meier's Civilization VI/AppOptions.txt` (verified present, line 75 currently `EnableTuner 0`; edit only with the game closed). One connection at a time; single-player only; tuner disables achievements; Auto End Turn must be off. **Handshake-brick warning (upstream-documented, civ6-mcp README:63–65: a failed handshake often hangs the tuner until the game process is recycled) — reconnect failures escalate to the operator rather than retrying forever; behavior WP1-validated.**
3. **Wire protocol (community-verified; every item WP1-live-validated):** frame = `[4B LE payload length][4B LE tag][NUL-terminated UTF-8 payload]`, length = payload bytes + 1 (UTF-8 byte count), excluding the 8 header bytes. Handshake: tag 4 `APP:` (identity), tag 4 `LSQ:` (alternating index/name pairs; Lua states discovered by name, never hardcoded index). Commands: tag 3 `CMD:<state_index>:<Lua code>`. Output frames prefixed `O\x00<context>: `; Lua errors `ERR:`; sentinel `---END---`; unsolicited messages drained.
4. **Transport semantics.** Credits: nace-ai/civ6-mcp for the 3-strike timeout, no-blind-replay, dirty-drain designs; our own: everything else. Per-command timeout 5 s (popup Phase-2 scan 15 s; probe commands 1–2 s); handshake timeout 10 s; up to 2 consecutive command timeouts tolerated, each returning an explicit per-command failure (never a silent empty result); 3rd consecutive raises ConnectionError; post-timeout dirty-drain window; reconnect-once-then-reconcile; **mutations are never re-sent without read-back proof of non-execution; mid-frame timeout invalidates the connection** (cancellation-safe decoder, max frame size; a consumed header with missing body would misframe the stream).
5. **VM routing — per-query matrix, live-probed, no blanket rule.** GameCore-required: per-unit skip/`FinishMoves`; unit promotion (`SetPromotion`); tech/civic setters (fallback when InGame `RequestPlayerOperation` fails); verification read-backs (except session-state verification, which runs InGame pre-submission); threat scans (player-visible only); AI-processing polling. InGame-required: overview (`GetFavor`), `CanProduce`/`GetCurrentProductionTypeHash`, diplomacy, policy-slot reads, most UI-facing queries. Every execute/verify VM pair is documented in the matrix file with recorded probe results. Promotion via `SetPromotion` is an upstream-derived approach that also resets unit damage and may not consume movement — **game-rule-equivalent postconditions are defined in WP3 and validated against native promotion live** (eligibility, HP, movement, notification, subsequent promotions); if the live check (P9) shows inequivalence, promotion is reclassified as model-action-with-engine-support only if a corrective operation restores rule-equivalent state, otherwise promotion support is dropped to defer/terminal and the benchmark's rules divergence is disclosed in the README — documentation alone does not satisfy the acceptance requirement.
6. **Build posture: independent implementation informed by upstream research.** Honest README framing: **the end-turn orchestration is a functional re-implementation of upstream civ6-mcp's documented behavior (same pipeline, same safeguards), independently written behind our GameState adapter shim; the harness adds** total degraded defaults, STACKED_UNITS unstack, mid-frame invalidation, max frame size, explicit per-command failures, decision-provenance tracking, fog-pure observations. Research notes (published in-repo) carry the full MIT license text (civ6-mcp, Liam Wilkinson 2026; pins: lmwilki/civ6-mcp @ dd201905 = codex-hl-civ6; nace-ai/civ6-mcp @ ef1946b7) alongside verbatim excerpts; nace-ai credited precisely (transport hardening, batch queries, action-space enumeration, artifact-choice/readiness queries, the 30-type blocker fixture). Provenance policy: adapted code retains MIT notices; adapted files listed in README. **Fallback: the end-turn orchestration subsystem swaps to adapted upstream civ6-mcp `end_turn.py` (pinned @ dd201905) behind the GameState shim** — the adapter contract is the policy-table file plus the GameState shim interface, so our additions (total degraded defaults, provenance tracking, fog purity, ledger semantics) remain ours and all acceptance gates re-run after the swap; the shim interface and adapter contract are WP3 day-1 deliverables with an early compatibility check at the day-5 simulation checkpoint.
7. **Text-state core; vision as flagged stretch goal** (screenshot commentary only if runway remains; never a correctness dependency).
8. **Model access:** mistral-large-4 via Studio API; key via `MISTRAL_API_KEY` env var; `.env` gitignored; no-secrets check in WP7. Model/version/sampling pinned and logged per call.

## 3. Architecture principles

- Typed action batches: strict JSON schema, turn/batch IDs, per-action results; in-order sequential execution, no rollback implied. Identifiers validate against enumerated game tables; the model never generates raw Lua. **Intent durably recorded BEFORE any mutation is sent.**
- **Recovery state machine.** States per action: `intent` (recorded, not sent) → `dispatched` (persisted **before the socket write** — a crash between the write and persisting the state must leave a `dispatched` record, never a replayable `intent`) → `sent` → `pending` → `confirmed` (read-back proves effect) / `uncertain` (timeout or disconnect before proof) / `rejected` (validated illegal). On harness restart: `intent` → safe to send; `dispatched`/`sent`/`pending`/`uncertain` → reconcile via read-back. Reconciliation settles within a bounded window — 60 s per ordinary action; **uncertain end-turn actions inherit the advancement deadline (≥ 10 min) instead**, since normal processing legitimately takes minutes; when the window expires inconclusively, quarantine escalates to the operator — never silently dropped, never resubmitted; dependent actions block on quarantined actions. Pending end-turn is cleared ONLY on observed turn advancement or verified non-execution. Crash-injection tests at four points: before send (after `intent`), after send (before `sent` persists — the WAL boundary), after execution before result persistence, between actions.
- Read-back verification first-class; retry taxonomy: parse error / illegal action / stale state / in-game no-op / transport error. **Safe-query contract:** no remote-tile `CanStartOperation` improvement probes (documented engine-corruption hazard in all three reference clones); no speculative `GetNextEscapingSpyID` (documented native-crash hazard); asserted in tests.
- Compact snapshot + bounded context; transcript never becomes state. **Snapshot elision policy** (beyond N cities: summary-only; idle/distant units elided first, never armed-in-contact ones). **Last-known tile cache:** turn stamps, invalidated on visibility change; **cold-start: revealed-but-not-visible mutable fields are unknown until observed**; **rollback contract: restoration binds to the save identity and the ledger offset captured when that save was created (a save-time checkpoint association recorded per save, not derived from the loaded turn's pre-advance snapshot — a save taken before exploration on turn T precedes that snapshot, so snapshot-derived cutoffs retain same-turn leaks); observations after the save-time checkpoint are discarded; an unmatched or absent checkpoint discards ALL observations of the loaded turn (conservative)**; cache truncated to the loaded save's checkpoint. Tests: cold start, reload, same-turn rollback after exploration.
- Strategy memory: current plan, falsifiable commitments with deadlines, threat hypotheses, reflections; pre/post-advance separation; reconciled with ledger on reload.
- Deterministic calculators (legal moves, path estimates, affordability, yields); LLM chooses among candidates.
- **Observation purity:** side-effect-free extracts (ghost-queue clear = separate recorded repair op); fog rules over the whole policy-facing pipeline (tiles, calculators, summaries, errors, diffs, memory); error messages sanitized; fog-integrity test over the full pipeline.
- Prompt cadence: economy ~10 turns, diplomacy ~20, settle/expansion ~30; numeric falsifiable reflections.
- Two-phase turn. **Budgets:** snapshot ≤ 8,000 tokens (elision policy above); tactical batch ≤ 15 actions per model call; repair cap 2; **the 6-minute per-turn wall-clock budget covers the model-action phase only** (snapshot → model calls → validation/execution → blocker resolution → end-turn submission); the advancement wait is a separate budget with the reference escalation ladder (2/3/5/10/15/20/30 s rungs, ≈9 min) and hang timeout ≥ 10 min; **post-expiry paths are themselves bounded**: degraded completion has its own deadline (2 min); reconciliation settlement 60 s per action; mid-processing diplomacy pauses run under the advancement budget, not the action-phase budget; repeated pauses are tested. Per-run spending cap recorded.

## 4. Degraded-turn policy (total)

When the model is unresponsive, the repair cap is exhausted, or the action-phase budget expires, every mandatory choice resolves via a scripted default chain (model override always available when responsive). Every chain ends in either a legal resolution or an explicit terminal state — never silence:

- research: calculator-priority pick (best science-per-turn affordable); civics: best culture-per-turn affordable.
- production (empty queue): first-affordable from the calculator priority list; **if nothing is affordable, build the cheapest available item; if the queue admits nothing at all, the chain terminates → hard stop with operator alert (the reference confirms an empty queue can block advancement).**
- policy slots: first available card; pantheon: first available belief; promotion: first available.
- incoming deal: reject; non-deal diplomacy session: respond NEGATIVE/EXIT (legality-verified); **if both responses are illegal, the chain terminates → hard stop with operator alert (`CloseSession` stays last-resort for orphaned sessions only).**
- UNITS/UNIT_NEEDS_ORDERS (moves remaining): batch skip-remaining (the engine auto-skips zero-move units only).
- STACKED_UNITS: scripted unstack first (move one unit of the pair to an adjacent legal tile, preferring the unit with more moves); **a stack with movement remaining but no legal adjacent destination terminates → hard stop (the zero-move case is P8's terminal classification).**
- CITY/DISTRICT_RANGE_ATTACK: attack best legal adjacent target; **hold fire when no legal target exists, with the blocker verified cleared by read-back afterward (hold-fire is a candidate the blocker loop accepts); if the blocker persists after hold-fire, the chain terminates → hard stop.**
- governor appointment: first affordable governor, assign to capital; **governor promotion: first affordable promotion (legality-guarded); a defer is accepted only if the blocker is verified cleared by read-back afterward, else the chain terminates → hard stop.**
- envoy: first recipient passing `CanGiveTokensToPlayer`; dedication: highest-scoring applicable; WC votes: reference default (§5.3).
- great people: patronize-gold → patronize-faith → points-based recruitment where the API admits it → reject-if-`CanRejectPerson` → explicit terminal state; **prophets: always rejected when possible, else patronize-with-faith** (keeps the religion flow out of v1).
- ARTIFACT: **credit the find to the acting player (self) or first offered claimant via `CHOOSE_ARTIFACT_PLAYER` semantics** (the blocker is claimant credit, not slot placement); forced-single-claimant and two-claimant cases tested.
- game over: clean termination (§5.6).

Degraded handling logs every defaulted decision with reason. **The degraded-completion deadline (2 min, §3) ends in a terminal state if unresolved: hard stop with operator alert.** **Hard stop with operator alert is reserved for:** unknown blocker types, game over handling failure, and states the policy table classifies terminal — which now includes: nothing-affordable production queues, unresolvable stacked units, illegal diplomacy responses, failed hold-fire and defer read-backs, unresolvable GP chains, and P6/P7/P12/P13 fallbacks.

## 5. End-turn orchestration (WP3 core)

Single submission of ACTION_ENDTURN, durable pending guard. Ordered pipeline:

1. **Popup pre-dismissal.** Two sets, both hardcoded with live availability checks (P4): (a) the batched Phase-1 set run every turn: InGamePopup, GenericPopup, PopupDialog, **BoostUnlockedPopup (eureka/inspiration — a probed (P11), not assumed, blocker of unit-skip commands)**, GreatWorkShowcase, WorldCongressPopup, WorldCongressIntro, plus LeaderScene hide and cinematic-camera reset; (b) the 10 exclusive-popup names with their exact `Popup`-suffixed forms: TechCivicCompletedPopup, NaturalWonderPopup, NaturalDisasterPopup, WonderBuiltPopup, EraCompletePopup, HistoricMoments, MomentPopup, ProjectBuiltPopup, RockBandPopup, RockBandMoviePopup. Heavier phased dismissal only when a popup state is found; dismissal in the popup's own Lua context; **verified by absence checks before submission.**
2. **Diplomacy precheck.** Sessions/deals → model action (degraded defaults above). **War declarations are informational and auto-dismissed ONLY for deal-free at-war sessions (an at-war civ's peace offer is a decision, not a war declaration — nace-verified nuance). Mid-poll, the dismissal consumes the in-flight request in the war-only path: pending flag cleared + resubmission iff the turn did not advance after a ≥30 s settlement window (P12 — an unchanged turn alone does not prove consumption); after agent-handled non-war sessions the flag persists and the game auto-continues with the original request — clearing + resending there is the documented turn-skip hazard.** `CloseSession` is last-resort for orphaned sessions only.
3. **WC vote gate.** Handler registered BEFORE submission (session opens/closes synchronously inside ACTION_ENDTURN). Default strategy (reference-verbatim): spread favor evenly, option A, target index 0; **the handler's 0-resolution early-return submits with no votes (the phantom-congress soft-lock fix); registration is never skipped while `is_in_session` even with 0 resolutions.**
4. **Notification blocker loop** (≤ 3 passes) over the live `EndTurnBlockingTypes` enum, seeded from lmwilki's documented map **plus nace's 30-type scheduler classification (of which 20 types + `NO_ENDTURN_BLOCKING` are live-dumped in the base-ruleset fixture; governor/dedication/emergency/WC classes rest on static classification + lmwilki's documented map, and are live-probed per the register — the loop reads the actual installed DLC's live enum at runtime). Per-class policy (scripted auto-resolve / model action with degraded default / hard stop) is written as a policy table file; classes and defaults per §4 and the classification; every class maps to a gauntlet case plus a degraded-default case (policy-to-test matrix).** Scripted auto-resolves match the reference exactly: GOVERNOR_IDLE (`SendActivated`+`Dismiss`), CONSIDER_GOVERNMENT_CHANGE, WORLD_CONGRESS_LOOK, disloyal/razed city keep, GIVE_INFLUENCE_TOKEN zero-token case, ghost queue (recorded repair op), stale research/civic/promotion clears (promotion-count formula `T1*(n+1)*(n+2)/2`), zero-move auto-skip, spy escape + dragnet (only under active blockers — speculative calls are crash hazards), WORLD_CONGRESS_SPECIAL_SESSION and other non-SESSION World Congress types (reference catch-all: name-contains-WORLD_CONGRESS). **`WORLD_CONGRESS_SESSION` is explicitly EXCLUDED from the catch-all (the reference hard-blocks it: "NEVER auto-resolve session blockers") — a session blocker reaching the loop means the gate failed; classification: re-register the handler, else hard stop.** **Blocker-query transport failure is fail-closed: treat as unknown blocker → hard stop (deliberate divergence from the reference's fail-open "proceeding anyway", logged).** Novel policies (not reference-derived, live-validated per register): EMERGENCY_NEEDS_ATTENTION decline (P6), GOVERNOR_OPPORTUNITY defer (P7). BELIEF/RELIGION prevented by prophet rejection; reached anyway → terminal. **Loop final state: if the ≤3 passes end with unresolved hard blockers and `UI.CanEndTurn()` is false, the outcome is terminal → hard stop, bounded by the 2-min degraded-completion deadline; the run never retries silently.**
5. **`UI.CanEndTurn()` escape hatch (last resort):** proceed when the game says the turn can end despite reported blockers; log divergence.
6. **Advancement polling.** GameCore-only turn polling; **game-over checks at four points** (entry, mid-poll at ≥10 s rungs — an opponent victory during their turn otherwise waits the full ladder — post-poll, post-advance); advancement = turn-number increase, **plus the local-player readiness conjunct (`IsTurnActive()` in GameCore) if and only if probe P5 validated during setup; if the probe is unsupported on this build, advancement = turn-number only (reference behavior, disclosed); if a previously validated probe fails at runtime, readiness is treated as unknown — investigate before the next action phase, never silently ignore**; **a single InGame diplomacy probe after ~45 s of silence** (repetition is the documented hang cause), one final InGame round at the hang timeout — **the final round's contents are enumerated: diplomacy sessions, pending deals, and a single popup-dismissal attempt (a popup arriving during AI processing would otherwise escalate to an operator reload when a dismissal would suffice); the reference's post-timeout ACTION_ENDTURN re-send is deliberately omitted as a duplicate-submission hazard**; ladder = reference shape (2/3/5/10/15/20/30 s ≈ 9 min), hang timeout ≥ 10 min; diplomatic pause → return control to the agent loop; quiet + timeout → structured `HANG:{turn}:{autosave}` report → **the pending-end-turn guard's disposition on HANG: the guard is NOT cleared by the timeout (an unchanged turn is not proof of non-execution); resubmission after a HANG is permitted only after operator intervention — a reload (guard reset via identity check) or a verified non-execution; in-session "fix without reload" cannot clear it.** → WP5 escalation.

**Out of scope v1, each with a default policy so play cannot stall (README lists all):** proactive diplomacy (peace stance; reactive only), trade routes, spies beyond escape/dragnet auto-pick, governors/dedications beyond defaults, religion beyond pantheon (prophets rejected), tile purchase, city focus, unit upgrades, city-states beyond the envoy default. **Victory-class disclosure:** with these exclusions the reachable victory classes are effectively science/score; the README and video pre-disclose this, including that an AI-declared war ends only by the AI's peace offer.
