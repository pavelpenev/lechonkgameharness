# Le Chonk Plays Freeciv: Design + Plan (v1 — normative, self-contained)

Challenge: Mistral Discord challenge — a harness letting `mistral-large-4` (Mistral Studio API) play Freeciv. Judged on complexity, performance, reproducibility. Submission: 2–3 min video, GitHub repo with README, development story, OSS disclosure required by the brief. This document supersedes the Civ6 design entirely; `design-plan-v6.md` is retained as non-normative reference only. Deadline is not treated as a plan constraint per user direction (the brief copy in goums/chonk-doom's CHALLENGE.md reads 2026-10-29 23:59 CET — verify in Discord when submitting).

## 1. Decision record

1. **Game: Freeciv**, via CivRealm's environment (github.com/bigai-ai/civrealm), NOT the game as such — the stack is: CivRealm Python client (WebSocket/JSON, descended from chris1869/freeciv-bot) → freeciv-proxy → freeciv-web server bundled in the `civrealm/freeciv-web` Docker image (a freeciv 3.3-dev build, capstring `+Freeciv.Web.Devel-3.3`). **CivRealm is dormant upstream (last push 2024-09-11; PyPI 0.1.2 frozen 2024-01) — we VENDOR it into this repo and patch it ourselves.** Patch set based on PR #7 (github.com/bigai-ai/civrealm/pull/7, opened 2026-09-08, unmerged): `research_name` wrong-lookup bug, broken autosettler/sentry actions (pid 74 drifted to `packet_unit_server_side_agent_set`), broken `ActExplore`, missing `activity`/`ssa_controller` observation fields, ray import made optional. PR #7's author reports full 150-turn games working post-patch on Python 3.12 without ray — this is the load-bearing feasibility evidence for the whole plan.
2. **Host topology: rhea runs everything game-side** (ssh alias `rhea` = captain@192.168.0.140; Ubuntu 26.04.1, Ryzen 3600 12 threads, 15 GB RAM, 211 GB free disk, no Docker/podman yet, Python 3.14.4). Dev machine (pav) holds the repo and does video/editing. Harness (agent loop + env) runs on rhea; artifacts (JSONL transcripts, saves, replay bundles) sync back via rsync. **Python: uv-managed 3.12 venv for the vendored CivRealm** (its pins — gymnasium 0.29.1, tornado 6.3.2, selenium 4.9.1 — predate 3.14; 3.12 is the PR-#7-validated version). Docker Engine must be installed on rhea (user approval pending — WP0 blocker).
3. **Interface: CivRealm's Gymnasium `FreecivBaseEnv` behind our own narrow adapter.** We do NOT reuse CivRealm's LLM wrapper or its baselines (BaseLang/Mastaba are literature, not our agent). Our adapter owns: observation formatting, candidate enumeration, legality checks, Mistral controller, provenance ledger, scripted comparator, replay artifacts. Docker image pinned **by digest** (`civrealm/freeciv-web`, tag 1.4.6 = `latest`, pushed 2024-04-03; digest recorded in the run manifest — tag `latest` predates tag 1.3.2, so tags are not trustworthy pins).
4. **Model access:** exact model ID `mistral-large-4` via Studio API (`mistral-large-latest` does NOT point at it — challenge brief); `MISTRAL_API_KEY` env var, never in repo/logs; structured outputs via Mistral `json_schema` (constrained decoding — confirmed in Mistral docs). **Budget: uncapped per user, but every call is logged (tokens, latency, cost estimate) and reported per turn/run** — cost telemetry is a performance input and honesty requirement, not a cap.
5. **Positioning (honest, non-negotiable):** "LLM plays Freeciv" is NOT novel — taso-labs/freeciv-llm ran an 8-model ~200-turn tournament (CivBench Season #001, Feb 2026; winner MiniMax M2.5 at $11.57/match), CivRealm ships LLM baselines, SAGA (arXiv 2606.29932) is the strongest published CivRealm agent. Our claimed contributions: (a) the model-vs-scripted **decision-provenance ledger** + honesty metrics (PMR and RAG@10 analogs, reason-but-don't-act, illegal-action taxonomy) — no surveyed project ships this; (b) reproducibility discipline (digest pinning, exported-checkpoint paired evaluation, replay artifacts); (c) harness engineering lessons; (d) first Mistral-model run in this niche (CivBench field had no Mistral model). README pre-discloses CivRealm as the OSS base — required by the challenge brief, which explicitly permits existing frameworks (precedent: chonk-doom on Vercel AI SDK, le-chonk-crafter on open-source Crafter).
6. **Fallback base:** if the CivRealm stack cannot be made to run headless on rhea after WP0's bounded fix attempts, switch to `matpuk/freeciv-mcp` (github.com/matpuk/freeciv-mcp) — an active MCP bot speaking the native JSON protocol of stock freeciv-server 3.2.6 (`--enable-json` build), with seed control, batched turn execution, and combat-odds queries. Its patterns (explicit seeds, batched `execute_turn`, `predict_combat_outcome`, two-level strategist) are borrowed regardless of which base wins. A second switch after WP0 is not permitted; beyond that, cut scope honestly (scenario demonstration) rather than rebuild.
7. **Licensing posture:** vendored CivRealm code is GPLv3+ (file headers govern; its pyproject metadata is self-contradictory — "GLP3.0" typo + stray LGPL classifier — ignore it) and is marked as such in-repo. Our own process-boundary harness code stays MIT. The freeciv-web image contains AGPLv3 client components — irrelevant for local challenge runs; we host nothing for remote users (that would trigger AGPL §13). README carries the full disclosure.
8. **Ruleset/server facts to pin in the run manifest:** the image's freeciv 3.3-dev server (NOT stock 3.2.6 — do not claim stock compatibility), capstring, CivRealm settings including `phasemode player` (sequential turns), `timeout 0`, raised `pingtimeout`, `randomly_generate_seeds: False` (CivRealm default is True — must be overridden), explicit mapseed/gameseed/agentseed, ruleset (image's bundled default), AI opponent type/difficulty, `autotoggle disabled` (prevent AI takeover of our player). NOTE: some settings CivRealm sends are freeciv-web-server customizations absent from stock mainline (e.g. `victories`) — a portability trap if we ever swap bases; documented, not fixed.

## 2. Research register (deep round, 2026-10-24 — findings baked into this plan)

Prior art, with lessons adopted:
- **taso-labs/freeciv-llm + CivBench tournament** (github.com/taso-labs/freeciv-llm; tasolabs.com blog, Feb 2026): LLM full games cost $7–40/match for capable cheap models (Claude up to $988). **Reason-but-don't-act** was the top differentiator (GPT-5.2: 75.8% of mentioned threats never acted on within ±2 turns) — we instrument this metric from day 1.
- **chonk-doom** (github.com/goums/chonk-doom, prior challenge entry): ~5.5k input tokens/turn, input ≈87% of cost; fixes = stable prefix caching, lean history (last turn full, older one-liners), batched `act` tool, interrupts on salient events; "bloopers" were fixed by harness changes (exact coordinates in text, not inferred) — not model changes. Video early: community voting is up-arrow driven.
- **SAGA** (arXiv 2606.29932): LLMs cannot infer spatial relations from raw coordinates — observation uses relative direction/distance statements plus exact coordinates, precomputed semantics.
- **Age of LLM** (arXiv 2606.24391): ~58% of illegal actions are fog/state errors, not format errors → illegal-action taxonomy (schema vs state/fog vs illegal) drives different remedies; replay format + static viewer as first-class artifacts.
- **CivBench paper** (arXiv 2609.02459, civ6): **PMR** (proactive monitoring rate — did the agent query key strategic state in time) and **RAG@10** (commitment follow-through within 10 turns; 48–66% across models) — both computed purely from logs; we adopt both as honesty metrics.
- **Vox Deorum** (arXiv 2512.18564): LLM macro + algorithmic tactical hybrid across 2,327 games — validates enumerate-then-choose (model picks among candidates; calculators own arithmetic/legality).
- **nace-ai/civ6-mcp Drex mode**: a full decisions-only scripted controller completes turns with no generative model → **our scripted comparator doubles as the degraded-default engine**; build it first.
- **TextStarCraft II CoS** (arXiv 2312.11865): two-tier observation (compact snapshot + delta report) is the standard answer to token budget.
- **Factorio LE** (arXiv 2503.09617): GPT-4o repeated one invalid operation 78× consecutively — bounded repair (cap 2) is mandatory; unbounded retry is the documented failure.
- **CivWorldBench** (arXiv 2610.16450, Freeciv-engine): belief inference is measurably separable from forecasting — supports fog-hygiene-as-pipeline-invariant.
- **CivRealm ecosystem gotchas** (all from primary sources): PyPI 0.1.2 hard pins; image frozen 2024-04; startup health check fragile (issue #6, port_utils pubstatus probe → wrap with retries and fail loudly); CivRealm deletes per-turn autosaves via the webapp's HTTP endpoint (→ our own checkpoint export path); `FreecivBaseEnv.reset(seed=)` does NOT set the game seed; `latest` image tag is not the newest tag.

## 3. Architecture

- **Turn pipeline:** compact snapshot + delta report → short strategy memory (current plan, falsifiable commitments with deadlines, threat hypotheses) → one Mistral call (structured `json_schema` batch, ≤20 actions, ≤2 total API attempts per turn incl. repair) → validate each action against enumerated legal candidates (ownership, freshness, legality — never raw coordinates from the model) → sequential execute with per-action read-back verification → explicit finish-phase → wait for next own phase. Mutations never re-sent without read-back proof of non-execution.
- **Turn state machine:** `ACTING -> FINISH_SENT -> WAITING -> NEXT_OWN_PHASE | GAME_OVER | FAILED`. Bounded watchdogs on every wait; a FAILED run terminates with artifacts, never hangs silently. No Civ6-style blocker gauntlet exists — Freeciv end turn is `phase_done`; unset production/unused moves are strategic choices, not UI blockers.
- **Observation purity:** fog hygiene is a pipeline invariant, not a prompt instruction. Distinguish unexplored / last-known / currently visible; a vanished enemy is NOT destroyed; server-filtered state still gets adapter tests. The illegal-action stream is fog telemetry (state-error share reported per run).
- **Action surface (v1):** units (adjacent move, found city, fortify/sentry, attack visible target, road/irrigation/mine where legal), cities (choose production), research (choose available tech), diplomacy (read status; decline/exit negotiations — first contact defaults to WAR in Freeciv, disclosed), finish phase. **Out of scope, each with an explicit default:** naval, air, spies, caravans/trade routes, advanced treaty construction, citizen optimization, tax/luxury tuning (stretch), religion-adjacent depth. README lists all exclusions.
- **Provenance ledger (frozen in transcript schema):** `model` / `continued_model_order` / `scripted_default` (with reason) / `engine_automatic` / `housekeeping`, recorded at policy-choice level with snapshot ID, offered candidates, choice, call ID, execution result, verification evidence. Demo gate: model participation on ≥80% of played turns containing decision opportunities, plus demonstrated model control of research, production, and expansion. Engine-automatic resolutions of new research/production choices are counted, not hidden.
- **Honesty metrics (all log-derived):** PMR analog (key strategic state queried within its window), RAG@10 analog (own commitments executed within 10 turns), reason-but-don't-act (threat named in reasoning, no action within ±2 turns), illegal-action taxonomy shares, provenance shares. Published per run.
- **Degraded defaults (small — Freeciv has no blocker gauntlet):** model unresponsive after repair cap → preserve current orders, finish phase; research/production requires a new target → model choice, else one published deterministic priority list, logged; unsupported incoming treaty → decline; unknown state or uncertain mutation → bounded fail-stop with artifacts. Every defaulted decision logged with reason.
- **Artifacts:** versioned JSONL transcript (schema-versioned, includes provenance + metrics inputs) → static HTML replay viewer (judges without the game can verify method); per-run manifest (image digest, capstring, seeds, ruleset, settings, model ID, sampling, prompt/schema hashes); exported start checkpoints checksummed for paired runs.

## 4. Work packages

**WP0 — rhea provisioning + CivRealm spike (day 1, decisive).** Install Docker Engine on rhea (user approval); uv-managed Python 3.12 venv; pull `civrealm/freeciv-web` by digest; vendor CivRealm + apply patch set (PR #7-based; only what our action surface needs); hardened startup (retries around the fragile pubstatus health check). *Spike acceptance:* headless reset, scripted settle/move/set-research/set-production, 10 phase advances, checkpoint export, all with no browser. *Cut rule:* bounded fix attempts (one working day); failure → switch to freeciv-mcp base (decision 6) or honest scenario-cut. No second base switch.

**WP1 — Adapter + state extractor + scripted comparator (day 2).** Typed snapshot/delta schema, candidate enumeration per domain, fog fixtures (unexplored/last-known/visible; vanished-enemy case), scripted comparator (settle-first, fixed research/production priorities, minimal defense) completing 20 turns unattended. *Cut rule:* optional diplomacy reads and stretch actions cut first; fog tests never cut. Build the comparator BEFORE the model loop (it is the degraded-default engine and the ledger's `scripted` class).

**WP2 — Mistral agent loop + ledger (day 3).** Studio client (retry/backoff, per-call logging), json_schema enforcement, prompt templates as versioned files (strategy + tactical + repair), memory module (pre/post-advance separation), provenance ledger, honesty metric computation. *Acceptance:* 10 model-driven turns with read-back-verified effects; degraded path exercised under fault injection (timeout, malformed output, invalid action); provenance + metrics report generated.

**WP3 — Lifecycle + paired-run plumbing (day 4).** Identical exported start checkpoint launches both policies (model + comparator); our own checkpoint export/preserve path (independent of CivRealm's autosave deletion); hang/disconnect injection ends bounded with artifacts, no AI takeover, no duplicate mutations; JSONL → static replay viewer. *Cut rule:* cut automatic crash recovery, never checkpoint reproducibility.

**WP4 — Evaluation + freeze (day 5).** Paired runs from identical checkpoints: target 2 pairs × 50 turns; cut rule (in order): second pair → horizon 50→25 — the same-start same-horizon pair itself is never cut. Metrics: score/turn curves (descriptive), cities/population/research progress, survival, invalid-action taxonomy, retries, tokens/cost/latency per turn, wall-clock per turn, all honesty metrics, provenance shares. Crashes/stalls separated from strategic losses. Honest pilot framing — no model-ranking claims. Feature freeze at end of day 5.

**WP5 — Packaging (day 6).** README (prerequisites incl. rhea topology, digest pin, venv recipe, OSS disclosure, licensing, exclusions + defaults, fog disclosure, honest positioning), dev story from day-0 devlog, 2–3 min video assembled progressively from recorded footage (fallback: 60–90 s cut), no-secrets check, fresh-environment setup executed as written. Submission buffer.

## 6. Risks

- **CivRealm stack age** (frozen 2024, 3.3-dev server, protocol drift): mitigated by PR #7's evidenced post-patch 150-turn games, vendoring, digest pinning, and the freeciv-mcp fallback. Primary residual risk; WP0 gate is decisive.
- **Python version:** host has 3.14, CivRealm pins predate it; mitigated by uv-managed 3.12 (the PR-#7-validated version).
- **AI-opponent nondeterminism:** classic-AI opponents are not proven deterministic given fixed seeds → evaluation instances pinned by exported checkpoints, not seeds alone; AI behavior disclosed as version-dependent.
- **Judging on "complexity" vs framework reuse:** addressed by honest framing + the provenance/honesty contribution, not by inflated claims.
- **Calendar:** 6 working days, no deadline pressure assumed; WP0/WP1 gates protect the rest; evaluation horizon cuts before anything else; video assembled progressively, not last.
- **Residual unknowns by design:** P9 fork-default behaviors may force narrow-scenario disclosure; combat odds may not be exposed through CivRealm's client (then attack decisions are candidate-gated without odds, disclosed).
